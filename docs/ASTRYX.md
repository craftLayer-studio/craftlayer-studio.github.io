# Astryx in the CraftLayer website

The site uses the Astryx design system (`@astryxdesign/core`, pinned `0.7.13`)
with a custom built theme. Full guide and component cheat-sheet:
`.claude/skills/astryx-design-system/SKILL.md` in the workspace root, or ask the CLI.

## How it is wired

| Piece | File |
|---|---|
| Reset + component CSS (`@layer reset`, `astryx-base`) | `src/app/globals.css` |
| Built theme CSS (`@layer astryx-theme`) | imported in `src/app/layout.tsx` |
| `<Theme theme={craftlayerTheme} mode="light">` + `<LinkProvider component={NextLink}>` | `src/app/providers.tsx` (`'use client'`) |
| Theme source | `src/themes/craftlayer/craftlayerTheme.ts` |
| Theme build output (generated, commit it) | `src/themes/craftlayer/craftlayer.{js,css,d.ts}`, `craftlayer.variants.d.ts` |
| Fonts | `src/app/fonts.ts` (next/font variables on `<html>`, read by the theme) |

`src/astryx-themes.ts` is generated by `astryx theme add` (neutral). The app
does not use it at runtime; do not hand-edit it.

## Rebuild the theme

Run after every change to `craftlayerTheme.ts` and after any Astryx upgrade:

```bash
pnpm theme:build    # astryx theme build src/themes/craftlayer/craftlayerTheme.ts
pnpm theme:check    # same with --check: fails if the committed output is stale
```

## Rules of thumb

- Look up props before use: `pnpm exec astryx component Button --dense`.
- `xstyle` does not work here (no StyleX compiler). Use `className` with CSS
  Modules or globals.css and theme tokens such as `var(--color-text-secondary)`.
  App CSS is unlayered, so it overrides Astryx; keep overrides small.
- Internal links: Astryx `Link`, `Button href` or `ClickableCard href` (they go
  through next/link). External links: `Link isExternalLink`.
- Real names: `Selector` (not Select), `RadioList` (not RadioGroup),
  `CollapsibleGroup`/`Collapsible` (not Accordion), `DropdownMenu` (not Menu),
  `TabList`/`Tab` (panels are your own markup), `useToast` for toasts.
- Project type labels use `Badge` with text from `projectTypeLabel` in
  `src/data/projects.ts`.
- `pnpm exec astryx doctor` checks the setup.
